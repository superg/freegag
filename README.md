This is an open source engine implementation of ГЭГ: Отвязное приключение (GAG: The Impotent Mystery) and ГЭГ+: Гарри в отпуске (GAG+: Harry on Vacation)

I started it 12 years ago but the project was on the back burner until very recently.

Current status is, game is fully ported to SDL and is completable on Windows, all found bugs were fixed and it looks really good.
Modern Windows is supported, 64-bit native build, high resolution, integer scaling, windowed and full screen modes. True color framebuffer, high quality audio mixing and embedded natively scripted save and load game dialogs. I am currently working on the Linux build and mac build will be next.
I will add compiled executables soon and there will be a better README later.
